THE PLATFORM

Core hardware capabilities

A common controller foundation for field sensing, equipment control and connected monitoring.

ESP32 processing

Embedded processing for sensor acquisition, control logic and communications.

RS485 · Modbus RTU

Interface with compatible industrial instruments and field devices.

4–20 mA inputs

Acquire measurements from compatible industrial current-loop transmitters.

Multi-protocol connectivity

LoRa, 4G/LTE, Wi-Fi and Bluetooth for flexible local and remote connectivity.

Cloud integration

Connect field data to dashboards, alerts and operational reporting.

Connectivity and sensor compatibility depend on the selected hardware configuration, external interfaces and application requirements.
